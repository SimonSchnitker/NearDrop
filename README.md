# NearDrop

Dieses Flutter-Projekt dient dazu, eine Alternative zu Apples AirDrop zu schaffen.
Mit dieser App können Dateien drahtlos mit Geräten in der Nähe ausgetauscht werden. Unterstützt werden Android, iOS, macOS und Windows. Die gegenseitige Erkennung von Geräten erfolgt über Bluethooth LE und NSD. Die Übertragung von Dateien erfolgt über WebRTC.
